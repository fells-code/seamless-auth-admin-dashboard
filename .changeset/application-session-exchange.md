Turn session exchange on or off for an application on the Applications page, so a native admin tool such as the Seamless CLI can sign in through the OpenID Provider. The setting is offered only to a first-party public client with a loopback or private-use redirect URI, the rule the API applies, and turning it off asks for confirmation because it signs out every session the application exchanged for. Applications also take notice action origins, the bare `https` origins an account notice's action link may point to, checked as the API checks them before step-up. Against an API older than v0.23 neither setting is sent, and the form says they need the upgrade.
