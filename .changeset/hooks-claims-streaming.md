Add Login hooks, Custom claims and Audit streaming pages. Login hooks: one per trigger with URL, timeout and failure mode explained, a signing secret shown once and rotation, a test call, and the invocation log; the page says break-glass and recovery sessions never call a hook. Custom claims: a JSON set per instance role, organization role or OpenID Provider client, with the reserved names and the shared per-token budget from the API, checked before step-up, the field the API refused, the order sources apply in, and which role wins when two roles of one kind set the same claim. Audit streaming: OTLP and syslog sinks whose credentials are env var names only, a test record, each sink's lag, last delivery and last failure, and a note that a turned-off sink still holds audit retention until it is deleted. Webhooks, Login hooks and Audit streaming sit in an Integrations group in the sidebar. The new audit events have categories and labels in the Events view, and `@seamless-auth/types` moves to 0.39.
