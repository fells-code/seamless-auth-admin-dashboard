Show and manage application links on the Applications page. A confidential application lists the public applications it acts for, and a public application lists the confidential ones acting for it. Admins with write access add and remove links after step-up, choosing only public applications of the same party, and a link the API refuses shows its reason. Read-only admins see the links without the controls, and an API older than v0.23 gets an upgrade message instead of retries.
